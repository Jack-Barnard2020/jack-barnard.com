# Jack Barnard - CLI Sudoku [GitHub]

Date Created: 2026-09-21
Last Modified: 2026-09-29

This porject is part of a series of "mini-projects" that are a part of the ELEC2300 module at the Uiversity of Southampton. The task was to create a command line interface (CLI) Soduku game in C++. It was required that the game could load a plain text file with a fornat and layout of my choosing, print the baord to the terminal, allow the user to input numbers into the board, check if the board is valid, and auto-solve the puzzle.

I choose to solve this problem by first considering only the game logic and user-interface whilst igonoring the auto-solve funcctionality. I chose to represent th board as a 2D array of integers, with 0 represeting an empty cell, the board was loaded from a simple 9x9 csv file. The user was able to input postion and values into the board by providing a battleships-style coordinate and value, for example "A1 5" would place a 5 in the top left cell of the board. The program would automatically check if the board was completed and valid after each input, and would print the board to the terminal after each input.

Once the game logic and in-game UI was completed, I then implemented two auto-solve algorithms depth-first search and constraint propagation. Both algorithms were able to solve the board correctly but the constraint propagation algorithm was significantly faster than depth-first search on harder puzzles. Choice of algorithm is chosen at compile time by defining a preprocessor macro.

A main menu was then added to the game, allowing the user to choose between different diffculties of puzzles, or quitting the game.
